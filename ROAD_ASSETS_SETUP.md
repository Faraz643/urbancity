# UrbanCity GLB road assets

Extract the supplied ZIP so this file exists:

`frontend/public/models/road/road-straight.glb`

Copy the remaining supplied road GLBs into that same folder for future bends, intersections, crossings, barriers and signs.

The current Road component now uses `road-straight.glb` while preserving the existing CityScene coordinates and road widths.

The GitHub connection available here can edit UTF-8 source files but cannot upload binary GLB files, so the binary assets must be copied into the public folder separately.
